# แบบกิจกรรมประจำวันใน Agent Office

เลือกพื้นที่แล้ว: **canteen ชั่วคราวต่อท้ายอาคาร เฉพาะช่วงมื้ออาหาร** ตามคำตอบผู้ใช้ รักษาภาพวาดใต้ดิน สวน สี และตัวละครเดิม ไม่เพิ่มระบบเงิน เลเวล หรือเควสต์

## ช่วงเวลาและกิจกรรมที่เสนอ

ใช้เวลาท้องถิ่นของเครื่อง เช่นเดียวกับระบบกลางวัน–กลางคืนเดิม ช่วงเวลาด้านล่างเป็นข้อเสนอสำหรับเวอร์ชันแรก

- **08:30–09:30 กาแฟเช้า:** มีเครื่องดื่ม/ขนมเล็ก ๆ ให้คนที่พักอยู่เดินไปหยิบ นั่งจิบ หรือคุยกันสั้น ๆ ใช้วัตถุเดิมและไม่เปิดชั้น canteen
- **11:50–12:10 อาหารมาส่ง:** รถ/จุดขายอาหารมีถุงและถาดอาหารเพิ่ม มีจังหวะส่งของ เตรียมโต๊ะ และ agent เดินขึ้นมารับอาหารหรือซื้อข้าวที่รถบนสวน เป็นกิจกรรมจำลอง ไม่เรียก API งานหรือสั่งซื้อจริง
- **12:00–12:45 รับมื้อเที่ยง:** คนที่พักอยู่ทยอยไปรับอาหาร แล้วนั่งกินตามที่นั่งว่าง มีท่าถือถาด กิน ดื่ม วางภาชนะ และเดินกลับ พักกินประมาณ60–120วินาทีของภาพเคลื่อนไหว ไม่จองลิฟต์ค้างตลอดมื้อ
- **12:45–13:00 เก็บมื้อเที่ยง:** หยุดเชิญเพิ่ม เก็บถาด/ทำความสะอาดหลังคนลุก และปิด canteen เมื่อคนออกครบ หากลิฟต์ติดคิวจะคงห้องไว้จนเดินทางกลับเสร็จ
- **15:00–15:30 ชาและขนมบ่าย:** กิจกรรมสั้น ๆ ในที่พักหรือสวนตามอากาศ ใช้จำนวนคนน้อยกว่ามื้อเที่ยง

## คนและพื้นที่

เชิญเฉพาะตัวละครที่พักอยู่ใน flow ปัจจุบันและยังอยู่ในออฟฟิศ ไม่ดึงประวัติงานเก่าหรือทีมที่กลับบ้านแล้วเข้ามา ไม่เรียกคนที่กำลังทำงาน รออนุมัติ รอคำตอบ หรือมีปัญหาอยู่ จำกัดคนร่วมมื้อพร้อมกันไม่เกิน4คน และสูงสุด8คนต่อมื้อ แต่ละคนร่วมได้ครั้งเดียว

สวนรับรวมได้4ตำแหน่ง โดยนับคนจัดงานเลี้ยงและที่นั่งที่จองไว้ด้วย ใช้สวนเมื่ออากาศในฉากไม่ใช่ฝน/พายุและมีที่ว่าง หากฝนตกหรือสวนเต็ม เปิด **canteen ร่วมชั่วคราว** ใต้ชั้นสุดท้ายที่มีอยู่ก่อนแถบประวัติ/ฐานดิน ไม่แทรกกลางอาคาร ไม่เปลี่ยนห้องพักส่วนตัวของแต่ละทีม

canteen เป็นห้องใต้ดินมุมเดิม มีเคาน์เตอร์อาหาร โต๊ะกินข้าวเล็ก4ที่ ถาด/แก้วและจุดคืนภาชนะ ใช้สไตล์วาดและแสงไม้โทนอุ่นเดียวกับฉากเดิม เมื่อฝนเริ่มตกขณะกินกลางสวน ให้เก็บอาหารและย้ายเข้าห้องด้วยการเดิน/ลิฟต์จริง จากนั้นกินต่อข้างในจนจบ ไม่ย้ายกลับออกมาทันทีเมื่อฝนหยุดเพื่อป้องกันการเดินสลับไปมา

## การเดินและสถานะ

เดินออกจากห้องพักผ่านประตูห้องหลัก ใช้ลิฟต์ตัวเดียวกับงานจริง รับอาหาร เลือกที่นั่ง กิน เก็บภาชนะ แล้วกลับตำแหน่งเดิม แยกการจองลิฟต์ขาไป/ขากลับออกจากเวลานั่งกิน งานจริง/คนเข้า–กลับบ้านมีความสำคัญกว่ากิจกรรมพัก หากได้งานใหม่ให้ยกเลิกกิจกรรมพักอย่างปลอดภัยและกลับไปทำงาน

ไม่แก้สถานะ agent/task/result/delivery ใน T3 ท่าทาง ชื่อกิจกรรม และอาหารเป็นชีวิตในฉากเท่านั้น คงป้ายชื่อและชนิด Claude/Codex เดิม ไม่แสดงคนส่งอาหารเป็น agent งานจริง

## เวลาและความต่อเนื่อง

ใช้ฝนจากระบบอากาศจำลองเดิมในฉาก ไม่เพิ่มบริการพยากรณ์อากาศภายนอก กำหนดกิจกรรม/เมนูรายวันแบบคงที่พอให้เปิดใหม่แล้วไม่สุ่มเปลี่ยนซ้ำ เก็บบันทึกการเข้าร่วมเล็ก ๆ ต่อวันเพื่อไม่จัดมื้อเดิมซ้ำเมื่อ reload/reconnect ไม่ย้อนเล่นกิจกรรมที่เลยเวลาไปแล้ว เมื่อเปิดแอปกลางช่วงเที่ยงยังร่วมมื้อปัจจุบันได้

เมื่อซ่อน/พักภาพ/ขาดการเชื่อมต่อ การเดินหยุดตามระบบเดิม กลับมาแล้วตรวจเวลาจริง อากาศ ที่นั่ง และสถานะคนใหม่ก่อนเดินต่อ ไม่เร่งเล่นกิจกรรมที่พลาดไป และไม่ยุบห้องที่ยังมีคนอยู่

## เกณฑ์ตรวจรับ

เวลาเที่ยง/หมดช่วง/เปลี่ยนวัน; ฝนและพายุ; สวนมีงานเลี้ยงหรือเต็ม; คนทำงาน/คนซ่อน/ทีมเก่าไม่ถูกเรียก; ไม่มีที่นั่งซ้อน; เดินผ่านประตูและใช้ตู้เดียว; อาหารไม่จองตู้ค้าง; งานจริงเข้ามาระหว่างกิน; reload/reconnect ไม่ซ้ำ; canteen ต่อท้ายและยุบหลังคนออกครบ; ภาพจริงหน้าต่างแคบยังอ่านออกและเข้ากับฉากเดิม

สถานะ: ผู้ใช้อนุมัติให้เริ่มตามแบบนี้แล้ว รวม canteen ชั่วคราวต่อท้ายอาคาร กำลังลงมือและตรวจทานก่อนส่งมอบ
